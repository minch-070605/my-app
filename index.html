01 / About

코드보다 시스템을 봅니다.

제가 관심 있는 분야는 사용자가 직접 보는 화면보다 그 뒤에서 서비스를 움직이는 서버와 데이터베이스입니다.

API가 어떻게 설계되는지, 데이터가 어떤 구조로 저장되는지, 요청이 들어와 응답으로 돌아가기까지 어떤 흐름을 거치는지 이해하는 것을 중요하게 생각합니다.

앞으로는 Java / Spring 기반의 백엔드 개발을 중심으로 SQL, RDBMS, 네트워크, 운영 환경까지 폭넓게 다루는 개발자로 성장하고자 합니다.
